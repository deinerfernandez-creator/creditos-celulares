# **App Name**: Tecnicell Créditos

## Core Features:

- Gestión de Clientes: Permite crear, ver y editar perfiles de clientes para mantener un registro de quienes solicitan créditos.
- Registro de Créditos: Capacidad para registrar nuevas solicitudes de crédito, especificando el monto inicial del préstamo y el plan de cuotas (6 o 12 quincenales).
- Cálculo Automático de Cuotas: Generación automática del calendario de pagos, calculando el monto total (original más 50% o 100% de recargo según el plan) y el valor de cada cuota quincenal.
- Registro de Pagos: Funcionalidad para registrar cada pago realizado por el cliente, actualizando automáticamente el saldo pendiente del crédito.
- Historial de Pagos Detallado: Visualización de un historial de transacciones detallado para cada crédito, mostrando todos los pagos realizados y los montos restantes.
- Panel de Control de Créditos: Un panel que ofrece una vista resumida de todos los créditos activos, próximos pagos y cuentas atrasadas para una gestión eficiente.
- Herramienta de Resumen de Crédito con IA: Una herramienta generativa de IA que provee resúmenes rápidos del estado crediticio de un cliente, incluyendo el saldo restante, la fecha del próximo pago y la consistencia de pagos históricos, para facilitar el servicio al cliente.

## Style Guidelines:

- Esquema de color principal: Un azul profesional y moderno (#225CCC) que transmite confianza y eficiencia, ideal para una aplicación de gestión financiera. 
- Color de fondo: Un azul muy claro y desaturado (#EEF3FC) que proporciona un lienzo limpio y legable para la información de la aplicación.
- Color de acento: Un cian vibrante y enérgico (#3DC9EE) que añade contraste y destaca elementos importantes o acciones en la interfaz.
- Fuente principal para titulares y cuerpo de texto: 'Inter' (sans-serif), elegida por su legibilidad, neutralidad y estética moderna, adecuada para una aplicación centrada en datos y claridad.
- Utilizar iconos lineales y limpios que complementen el diseño moderno de la interfaz, adecuados para temas financieros y de gestión.
- Diseño responsivo y estructurado, con tablas claras y componentes de entrada de datos intuitivos para una navegación eficiente.
- Animaciones sutiles en las transiciones de página y en las interacciones de los elementos de la UI para una experiencia de usuario fluida.
